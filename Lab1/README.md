# Лабораторная работа №1

Отладка в среде разработки, цифровые порты ввода-вывода: бесконечный цикл с задержкой, счётчик, гармонический сигнал, мигание светодиодом и смена частоты мигания кнопкой.

Пояснения к коду даны в главе 1 методички.

## Задание

В основном цикле: задержка 1–2 мс, приращение счётчика `count_main` на 1 и расчёт сигнала `x(t) = sin(0,001·π·count_main)`. Нужно:

1. Вывести значения `count_main` и `x` в окно отладки в реальном времени.
2. Поставить точки останова в основном цикле и пройти его по шагам.
3. Вывести график `x(t)` с помощью Serial Wire Viewer.
4. Переключать светодиод (PC6) раз в N проходов цикла.
5. Менять частоту мигания с 2 Гц на 10 Гц, пока удерживается пользовательская кнопка (PC13).
6. Составить отчёт: снимок экрана с окном отладки, график сигнала, код программы.

## Файлы

| Файл     | Что в нём                                                                                                  |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| `main.c` | фрагменты для проекта CubeIDE: блоки `Includes`, `PV` (переменные и константа) и `USER CODE 3` (цикл)     |

Остальной код проекта создаёт CubeMX. Отчёт (скриншоты) в репозиторий не входит.

## Что делает программа

1. Каждый проход цикла: `count_main` увеличивается на 1, считается `x = sin(0,001·π·count_main)`.
2. `HAL_Delay(1)` на деле ждёт 2 мс: функция добавляет к ожиданию один такт SysTick. Поэтому длительность прохода в программе задана явно, `LOOP_MS = 2`.
3. Светодиод переключается раз в `half_period_ms / LOOP_MS` проходов. Обычно `half_period_ms = 250`, то есть каждые 125 проходов, или 250 мс: период мигания 500 мс, частота 2 Гц.
4. Если на PC13 высокий уровень (кнопка удерживается), `half_period_ms = 50`: переключение каждые 25 проходов, период 100 мс, частота 10 Гц.
5. Сигнал `x` имеет амплитуду 1 и период 2000 проходов, то есть около 4 с. Переменные `count_main` и `x` объявлены `volatile`, чтобы отладчик мог их показывать.

## Настройки CubeMX

| Что                       | Значение                                                                                               |
| ------------------------- | ------------------------------------------------------------------------------------------------------ |
| Плата                     | Nucleo на STM32G474RE (Board Selector)                                                                 |
| Тактирование              | оставьте по умолчанию и запомните SYSCLK: ту же частоту нужно указать в SWV (в Lab2 это 170 МГц)       |
| SYS, Debug                | Serial Wire                                                                                            |
| PC6                       | GPIO_Output (светодиод по заданию)                                                                     |
| PC13                      | GPIO_Input, Pull-down (кнопка без нажатия даёт «0»)                                                    |

Светодиод на Nucleo-G474RE (LD2) подключён к PA5, а не к PC6, как в задании. Если работаете на этой плате, настройте PA5 как GPIO_Output и замените в коде `GPIOC, GPIO_PIN_6` на `GPIOA, GPIO_PIN_5`.

## Куда вставить код

Содержимое `main.c` вставляется между метками `USER CODE` проекта: подключение `math.h` в `USER CODE BEGIN Includes`, переменные и `LOOP_MS` в `USER CODE BEGIN PV`, тело цикла между `USER CODE BEGIN 3` и `USER CODE END 3`.

## Отладка

1. Live Expressions: добавьте `count_main` и `x`, они обновляются на ходу. Переменная должна быть глобальной и `volatile`.
2. Точки останова: двойной щелчок по номеру строки слева от кода; дальше Step Over (F6), Step Into (F5), Resume (F8).
3. График в SWV: Run → Debug Configuration → Debugger, включить Serial Wire Viewer, указать Core Clock, равный SYSCLK. После запуска отладки Window → Show View → SWV → SWV Data Trace Timeline Graph, в Configure Trace добавить `x`, запустить трассировку и продолжить выполнение.

## Что должно получиться

- В SWV: синусоида `x` с амплитудой 1 и периодом около 4 с.
- Светодиод мигает с частотой 2 Гц, при удержании кнопки 10 Гц.

Логика цикла проверена расчётом на компьютере: за 2000 проходов (4 с при 2 мс на проход) светодиод переключается 16 раз без нажатия (2 Гц) и 80 раз при высоком уровне на кнопке (10 Гц), `x` меняется от −1 до 1.

## Ограничения

- Код рассчитан на кнопку, которая при нажатии даёт высокий уровень (режим pull-down, как в задании). Если на вашей плате нажатие даёт низкий уровень, частоты поменяются местами.
- Точная частота зависит от `HAL_Delay`: период прохода 2 мс получен из поведения HAL, а не измерен.
