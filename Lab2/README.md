# Лабораторная работа №2

Прерывания по таймеру, мигание светодиодом, управление частотой кнопкой, корректирующие устройства W1 и W2 с периодом квантования 1 мс.

Пояснения к коду даны в главе 2 методички.

## Файлы

| Файл             | Что в нём                                                                                                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `main.c`         | проект CubeIDE ; код лабораторной в блоках `USER CODE 0` (переменные, константы, обработчики), `USER CODE 2` (запуск таймера) и `MX_GPIO_Init_2` (подключение прерывания кнопки) |
| `stm32g4xx_it.c` | обработчик `EXTI15_10_IRQHandler` в блоке `USER CODE 0`                                                                                                                          |

Остальные файлы проекта (`system_stm32g4xx.c`, `syscalls.c`, `sysmem.c`, `stm32g4xx_hal_msp.c` ) создаются CubeIDE сами и кода лабораторной не содержат.

## Что делает программа

1. TIM2 вызывает прерывание каждую 1 мс (1 кГц).
2. В обработчике таймера переключается светодиод: раз в 1 с при частоте 1 Гц и раз в 100 мс при 10 Гц.
3. В том же обработчике считается гармонический сигнал `signal = A·sin(2π·f·t)`, где A = 1, f = 1 или 10 Гц.
4. Кнопка PC13 по прерыванию переключает частоту 1 Гц и 10 Гц. Дребезг подавляется программно (50 мс).
5. Считаются выходы двух звеньев при задающем сигнале `x(t) = 0,5·sign(sin(0,05·π·t)) + 0,5` (меандр с периодом 40 с, значения 0 и 1): `y1` для W1 и `y2` для W2.

Параметры варианта: k = 5, T1 = 0,1 с, ζ = 0,25, T2 = 0,1 с.

- W1 = 5 / (0,01·S² + 0,05·S + 1)
- W2 = 5 / (S·(0,1·S + 1))

## Константы звеньев

Разностное уравнение в обработчике:

`y[n] = B0·x[n] + B1·x[n-1] + B2·x[n-2] − A1·y[n-1] − A2·y[n-2]`

Коэффициенты получены билинейным преобразованием при T_s = 1 мс.

- Перед `A1` в формуле стоит минус, поэтому `A1_1` и `A2_1` в коде **отрицательные**.
- Знаков после запятой нужно не меньше 8. Сумма `1 + A1 + A2` для W1 порядка 1e-4, и коэффициент усиления на постоянном токе (должен быть 5) зависит от её точности. При округлении `A1` до 5 знаков усиление получается около 12,5.
- У интегратора W2 сумма `1 + A1 + A2` равна нулю точно, иначе выход «течёт». Поэтому `A2_2 = −(1 + A2_1)`.

## Просмотр графиков (SWV)

1. Run → Debug Configuration → Debugger: включить Serial Wire Viewer, Core Clock 170 МГц.
2. Window → Show View → SWV → SWV Data Trace Timeline Graph.
3. Configure Trace: добавить переменные `signal`, `y1`, `y2`, запустить трассировку и продолжить выполнение.

## Что должно получиться

- `signal`: синусоида амплитудой 1, частота меняется с 1 на 10 Гц по нажатию кнопки.
- `y1` (W1): выходит на 5 с выбросом до 7,2 (около 0,33 с). Когда задающий сигнал падает до 0 (на 20-й секунде), возвращается к 0.
- `y2` (W2): линейно растёт со скоростью около 5 в секунду до примерно 99 к 20 с, затем держится. С 40-й секунды снова растёт.
- Светодиод: переключение раз в 1 с, после нажатия кнопки раз в 100 мс.
