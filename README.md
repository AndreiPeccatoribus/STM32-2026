# STM32-2026

Код лабораторных работ и курсовой работы по четвёртой части курса «Управление в технических системах» (МГТУ им. Н. Э. Баумана): корректирующие устройства дискретных систем управления и их реализация на микроконтроллерах STM32. Репозиторий, на который ссылается методическое пособие к этой части курса; пояснения к коду даны в главах пособия.

Примеры написаны для серии STM32G4 (ядро Cortex-M4F), в описаниях работ используется плата Nucleo-G474RE с тактовой частотой 170 МГц. Для другой серии нужно пересчитать предделитель и период таймера.

## Что в репозитории

Лежит только то, что написано вручную: файлы с кодом и пояснения к ним. Файла конфигурации CubeMX (`.ioc`) и остальных файлов проекта CubeIDE здесь нет: настройки описаны в README работы, по ним проект создаётся заново.

## Как пользоваться

1. Создайте в STM32CubeIDE проект для своей платы и настройте периферию по README нужной работы.
2. Скопируйте код в проект. Копируйте содержимое пользовательских секций (между `USER CODE BEGIN` и `USER CODE END`), а не файл целиком: тогда при повторной генерации кода CubeMX ваши вставки сохранятся.
3. Сверьте имена дескрипторов (`htim2`, `htim6`, `hadc1`, `hdac1`) со сгенерированным кодом: они зависят от настроек проекта.

Файл `main.c` устроен в каждой работе по-своему:

## Светодиод и кнопка

В заданиях светодиод подключён к PC6, а пользовательская кнопка к PC13. На Nucleo-G474RE светодиод LD2 подключён к PA5, кнопка B1 к PC13. Поэтому:

- в `Lab1` код написан под PC6 по заданию; для Nucleo-G474RE замените `GPIOC, GPIO_PIN_6` на `GPIOA, GPIO_PIN_5` (описано в README работы);
- в `Lab2` светодиод уже на PA5.

## Что понадобится

- STM32CubeIDE (со встроенным CubeMX);
- плата серии STM32G4 с ST-LINK и кабель USB; для `Lab1`, `Lab2`, `Lab4` и `Coursework` пригодится Serial Wire Viewer (SWV), порядок включения описан в README работ;
- для `Coursework`: MATLAB с Simulink и Control System Toolbox, компилятор Си для блока C Caller, генератор сигналов и осциллограф (схема подключения в README работы); функцию фильтра можно проверить на компьютере и без MATLAB;
- для `Lab4`: Python с NumPy для расчёта показателей по записанным данным (необязательно, скрипт приведён в README).
